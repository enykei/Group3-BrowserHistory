# Browser History Mini-Project

| File | Purpose |
|---|---|
| node.py | Node (url, title, timestamp, prev, next) |
| doubly_linked_list.py | Hand-written doubly linked list |
| stack.py | Hand-written stack for deleted pages |
| browser_history.py | BrowserHistory manager (all required operations) |
| main.py | Interactive prompt-menu browser: `python main.py [capacity]` |
| demo.py | Scripted demo of every feature: `python demo.py` |
| tests/test_browser_history.py | Unit tests: `python -m unittest discover -s tests -v` |
